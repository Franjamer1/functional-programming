Actividad: Procesamiento de una frase Diseña un algoritmo que realice las siguientes acciones: Solicita al usuario que ingrese una frase, asegurándote de que no exceda los 100 caracteres de longitud. Si la frase supera este límite, el programa deberá mostrar un mensaje de advertencia y volver a solicitar el ingreso hasta que se cumpla la condición. Una vez ingresada una frase válida, el algoritmo debe recorrerla carácter por carácter y separar su contenido en dos vectores: Un vector para almacenar únicamente las vocales (A, E, I, O, U), en mayúsculas o minúsculas. Otro vector para almacenar las consonantes, espacios y caracteres especiales, manteniendo el mismo orden en que aparecen en la frase original. El programa debe incluir un subprograma que se encargue de: Mostrar el contenido de cada vector. Indicar la cantidad total de elementos almacenados en cada uno.
