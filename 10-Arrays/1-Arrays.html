Actividad 1: Ejemplo guiado - Uso de vector Crea un programa que solicite al usuario ingresar 5 valores numéricos, los almacene en un único arreglo (vector) y luego los muestre por pantalla. Declara el tipo de dato que almacenará el vector (en este caso, números enteros). Define la dimensión del arreglo (en este caso, debe tener capacidad para 5 elementos). Utiliza un bucle para recorrer el vector posición por posición y pedir al usuario que introduzca un dato. Puedes utilizar una estructura de repetición "Para" para esta tarea. Una vez cargado el vector, recórrelo nuevamente para mostrar los valores almacenados por pantalla.
